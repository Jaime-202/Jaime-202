- 🧬 **Sistemas & Esolangs**: Creador de **[Parásito](https://github.com/Jaime-202/Parasito)**, un lenguaje esotérico que opera esteganográficamente en comentarios de Python sin sintaxis propia.
- ⚙️ **Backend & Web**: Desarrollo de APIs REST y servicios ligeros en **Go (Golang)** y JavaScript.
- 🤖 **IA Aplicada**: Integración de modelos multimodales (Gemini API) y motores heurísticos locales para análisis en dispositivo.
